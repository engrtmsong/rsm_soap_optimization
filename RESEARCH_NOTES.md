# Research provenance, validation and limitations

## Purpose

This repository is a **Python teaching and methodology demonstration** of response surface modeling, based on the broad approach of a 2025 undergraduate chemical engineering research project on soap production from *Balanites aegyptiaca* seed oil.

## What is original, and what is illustrative?

- The author's **undergraduate research topic** and broad use of DoE/RSM are documented in the academic CV.
- The **Python script** is a computational demonstration.
- The **response values generated by the script are synthetic/representative**, not laboratory measurements from the thesis.
- Fitted coefficients, p-values, R² and predicted optimum from the script describe **only the synthetic dataset** and are not evidence of laboratory yield or industrial performance.

## Factors and units

| Factor | Script range | Unit |
|---|---:|---|
| Reaction temperature | 50–80 | °C |
| NaOH concentration | 10–20 | % (basis should be specified for real experimental reuse) |
| Reaction time | 30–90 | minutes |
| Modeled response | synthetic soap yield | % |

The script constructs a three-factor face-centered central composite design with 8 factorial, 6 axial and 6 center points. The factor ranges are **demonstration choices** and should not be represented as independently verified operating recommendations.

## Statistical interpretation

The script fits a quadratic model and reports coefficient-level t-tests. **Individual coefficient p-values are not the same as an overall model F-test**. The generated optimum is a mathematical prediction constrained to the chosen factor ranges; it is not experimentally validated. No external test set, uncertainty intervals, residual diagnostic suite, or replicated confirmatory experiments are included.

## Reproducibility

Install dependencies from [requirements.txt](requirements.txt) and run:

```bash
python rsm_soap_optimization.py
```

The script writes generated files into `outputs/`. The directory is intentionally excluded from Git because these are reproducible generated artifacts. The GitHub Actions smoke test checks that the pipeline executes and creates nonempty outputs; **passing that test does not prove chemical validity**.
