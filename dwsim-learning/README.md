# DWSIM Process Simulation Learning Portfolio

**Status: In progress — foundational learning.** This project documents an early-career chemical engineer's progression toward reproducible process simulation. **No completed DWSIM flowsheet or validated simulation result has been uploaded to this repository yet.**

## Why this project matters

Process simulation helps engineers understand material and energy balances, phase behavior, thermodynamic models and unit operations. My goal is to build transparent, checkable simulation case studies using the free DWSIM simulator.

## Current learning stage

- Material stream setup and interpretation
- Specifying temperature, pressure and flow rate
- Identifying liquid/vapor phase behavior
- Understanding how thermodynamic assumptions affect calculated properties

## Evidence standard for a completed case

A case will only be marked **completed** after a working DWSIM project file, input assumptions, results and an independent reasonableness/validation check have been added. Simulation outputs will be clearly labelled as predictions, not experimental measurements.
